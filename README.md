## Features

| Feature          | Description                                                 |
| ---------------- | ----------------------------------------------------------- |
| Model Rankings   | Multi-dimensional rankings, benchmarks and trends           |
| Release Tracking | Newest & open-source releases                               |
| News Aggregation | RSS: industry / open source / hardware / funding / research |
| Model Comparison | Radar metrics, pricing, cost estimator                      |
| Source Status    | Availability & latency monitoring                           |

## Quick Start

Requires Node.js ≥ 22.22

```bash
npm install
npm run dev      # client + Worker API at http://localhost:3000
```

`wrangler dev` for raw Worker parity (port 8787)

## Commands

| Command              | Description                  |
| -------------------- | ---------------------------- |
| `npm run dev`        | Dev server (port 3000)       |
| `npm run build`      | Production build             |
| `npm run preview`    | Preview the production build |
| `npm run deploy`     | Build and deploy to Workers  |
| `npm run test`       | Tests (Vitest)               |
| `npm run lint`       | Static analysis (oxlint)     |
| `npm run type-check` | Type checking (tsc)          |
| `npm run format`     | Code formatting (oxfmt)      |
| `npm run audit`      | Dependency security scan     |

`build` also runs `type-check`, `i18n:check`, and boundary guards

## Deployment

One Worker serves the site and API; cron refreshes the cache every 30 minutes

1. Fork the repository
2. (Recommended) Create a KV namespace and replace the ID in `wrangler.jsonc`
3. (Optional) `npx wrangler secret put HF_TOKEN` with a read-only [HF token](https://huggingface.co/settings/tokens) for Hugging Face routes
4. Import the repo in Workers & Pages → Save and Deploy

|                | Without KV   | With KV              |
| -------------- | ------------ | -------------------- |
| Data           | Memory cache | KV cache (30m/2h/6h) |
| Status history | Memory only  | 90-day history       |

Rate limiting is always in-memory, without `kv_namespaces` the app falls back to memory + browser/CDN cache

`worker-configuration.d.ts` is generated by `npx wrangler types` — don't edit it by hand
